# Frontier 2026 Sponsors — Strategic Map

## 🟣 Phantom (Grand Prize Sponsor — most leverage)
- **What they want**: Apps that **distribute via wallet** (5M+ user base they can tap)
- **Recent priorities (2026)**: 
  - Multi-chain (Solana + ETH + Polygon)
  - **MCP server for AI agents** ⭐ Phantom prioritizes AI agent wallets
  - Mobile via universal links/deeplinks
  - React SDK + Server SDK
  - Token Extensions support
- **Workshop**: Phantom Connect (Apr 21, Brian Friel)
- **Integration sweet-spot**: AI agent → Phantom MCP, mobile dApp → deeplink, Blinks → wallet rendering
- **Contact**: developers@phantom.app, @brianfriel on Telegram

## 🔵 Privy
- **Track record**: 8.5M+ users onboarded via embedded wallets
- **What they want**: Apps that solve **drop-off** — every "wallet popup" is bad UX
- **Recent priorities**:
  - Email/SMS/social/passkey/wallet auth (any login → wallet)
  - Embedded wallets that hide crypto entirely
  - **Account funding** integration (MoonPay + Coinbase Pay built-in)
  - Gasless transactions / sponsored fees
  - Cross-chain liquidity
- **Hackathon strategy**: Bounties + API credits historically (ETHGlobal, Solana Hyperdrive)
- **Integration sweet-spot**: Any consumer app where user shouldn't see wallet/seed phrase
- **Solana Developer Platform partner**: Privy powers SDP wallet infrastructure

## 🟢 Arcium (MPC Privacy)
- **Track record**: Solana Privacy Hack Jan 2026 ($100K+ prizes), 30+ apps deployed in testnet, 300+ hackathon submissions across ecosystem
- **What they want**: Confidential compute use cases that NEED privacy
- **Notable winners using Arcium**: 
  - **Melee Markets** ($20K Breakout 2nd Place — used Arcium!)
  - Umbra, Vanish Trade, Anonmesh
  - **Encrypted Poker** (most cited demo)
- **Use cases they highlight**:
  - Private DeFi (private swaps, lending)
  - Hidden-info gaming (poker, strategy games)
  - AI training on private data
  - Multi-party data collaboration (hospitals, pharma)
- **Tech**: Arcis = Rust DSL extending Anchor. Mark function as `[confidential]` — no crypto expertise needed
- **Integration sweet-spot**: Anything where "privacy unlocks new market" — sealed bids, private auction, hidden-state games

## 🟠 MoonPay
- **Coverage**: 160+ countries, multi-fiat
- **What they want**: Apps that drive fiat → crypto volume
- **Recent priorities (2026)**:
  - **MoonPay Agents** = onramp for AI agents ⭐ (CLI for AI agents)
  - Widget/SDK/API integration in minutes
  - Solflare partnership as case study
- **Integration sweet-spot**: Any app where user wants to spend money in crypto → integrate MoonPay widget
