TIDE3 / 12 — The Insight

How It Works

Encrypt → Aggregate → Swap → Distribute

Many users commit encrypted intents into a shared window. The pool aggregates inside an Arcium MXE. A single atomic Jupiter swap executes the full amount. Pro-rata allocations distribute back.

1

Commit

Users encrypt amount + slippage with Arcium SDK. Hash + escrow on-chain. No intent visible to bots.

2

Aggregate

Arcium MPC nodes sum encrypted intents inside the MXE. Public output: total USDC + count only.

3

Swap

Single Jupiter v6 IOC swap via PDA-signed CPI. Atomic. Window-time Pyth oracle pinned for fairness.

4

Distribute

Pro-rata SOL allocations. Users claim. Bots had nothing to front-run because the order was never public.
